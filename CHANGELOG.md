# Changelog

## 1.0.0

- Initial public release under the `mood_swings` mod ID.
- Added six configurable custom mood tasks.
- Added exact civilian and killer task text while preserving Wathe's native HUD.
- Added reusable named cuboid areas stored per save.
- Added random-area targets for `strange_noise`.
- Added distance tracking for `walk` with teleport-step rejection.
- Added per-save enable and disable controls for native and custom tasks.
- Added an AutoConfig/Cloth Config menu with optional Mod Menu integration.
- Fixed custom and forced tasks returning to normal Wathe task rotation.
